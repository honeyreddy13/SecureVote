# Secure Vote 🗳️

Secure Vote is an Android application designed to offer a secure, intuitive, and user-friendly digital voting experience. This app allows citizens to vote digitally in major elections, including Lok Sabha, State Assembly, Panchayat, Municipal Corporation, and Sarpanch elections.

## Features

- 🧩 **Animated Election Tiles**  
  Engaging UI with five interactive CardViews for each election category.

- 📊 **Ongoing Polls Section**  
  Horizontally scrollable view displaying ongoing polls with real-time voting progress.

- 🔐 **Secure Navigation**  
  Intent-based navigation to each voting module ensures a smooth and safe user journey.

- 📱 **Modern UI Design**  
  Built using Material Design principles for an intuitive user experience.
